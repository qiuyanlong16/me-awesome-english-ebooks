Some in techland fear that the bots will leave users vulnerable to new threats such as prompt injections, where an attacker sneaks text to an AI through a website’s computer code and deceives it into misbehaving. The companies seem to be taking these concerns seriously. Meta assigns a private server for each Muse user to hold their data and operate their assistant.
